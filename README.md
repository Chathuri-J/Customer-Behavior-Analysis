Data Analytics Project: End-to-End Analysis & Dashboarding
Overview

This project demonstrates a complete data analytics workflow, starting from loading raw data in Python to building an interactive dashboard in Power BI.
The goal is to extract meaningful insights using EDA, data cleaning, SQL analysis, and visualization.

The project showcases practical skills relevant to Data Analyst / BI Analyst roles.

Dataset

The dataset contains structured data related to business transactions and customer information.

Loaded and processed using Python (Pandas).

Cleaned and stored in a PostgreSQL database for further analysis.

Note: Dataset used for educational and portfolio purposes.

Tools & Technologies

Python (Pandas, NumPy, Matplotlib/Seaborn)

Jupyter Notebook

PostgreSQL

pgAdmin 4

SQL

Power BI

GitHub

Project Steps
Data Loading (Python)

Imported the dataset into Python using Pandas.

Checked data types, missing values, and basic structure.

Exploratory Data Analysis (EDA)

Analyzed distributions, trends, and patterns.

Identified inconsistencies and potential data quality issues.

Created summary statistics and visualizations.

Data Cleaning

Handled missing values.

Standardized column names and data formats.

Created derived columns (e.g., Age Group) for better analysis.

Database Integration (PostgreSQL)

Loaded cleaned data from Python into PostgreSQL using SQLAlchemy.

Verified table structure using pgAdmin.

SQL Analysis

Ran SQL queries to:

Aggregate data

Analyze trends by categories

Extract insights for dashboarding

Power BI Dashboard

Connected Power BI to PostgreSQL.

Built interactive dashboards with:

KPIs

Filters

Charts and summaries

Designed for clear business insights and decision-making.

Dashboard & Results

The Power BI dashboard highlights:

Key performance indicators (KPIs)

Trends across different categories

Comparative analysis using filters and slicers

Open the Jupyter Notebook and run all cells to:

Load data

Perform EDA and cleaning

Push data to PostgreSQL

Open the Power BI file (.pbix) and refresh data.
